# 未完成与待实机验收

本次代码整理保留以下事项，未将编译或单元测试通过误报为完整实机验收：

- 需要在用户实际的 Magic Keyboard、不同键盘布局、输入法、数字小键盘和媒体键上逐项验收事件显示、组合键和重复键行为。
- 需要在多个显示器、不同缩放比例和窗口调整后目视验收剪贴板面板布局及趋势图；当前未进行完整 UI 自动化回归。
- 需要用户明确选择同步文件夹并开启对应内容类型后，验证大文件、目录、图片、文本、重名、重启、暂停/恢复和 iCloud Drive 实际可用空间/权限错误。
- 剪贴板私有格式、部分富文本附件和无法从 NSPasteboard 导出的内容不能保证无损恢复；代码会报告失败或保留可恢复的公开格式。
- Quartz/AppKit 键鼠事件没有可靠的物理蓝牙设备归属；只有 HID 提供产品属性时才显示设备名称，不能把系统事件强行映射到某个蓝牙设备。
- macOS TCC 输入监控、辅助功能和 Secure Event Input 仍由系统控制，需在目标机器上按真实签名和路径确认。

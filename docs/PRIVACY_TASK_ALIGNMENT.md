# Nexus 隐私要求逐项对照（2026-11-21）

范围：基于 `task.md` 原文与 PR #56 之后、PR #57 的开发源码进行静态审计；未接触实际安装包、用户数据库、Apple 账户或生产 API。**`task.md` 不得因本报告而被改写。**

## 结论

任务中存在相互冲突的隐私规定，无法将所有文字同时作为产品行为实现。尤其是：

- 第 4.3 节要求记录用户输入、密码、验证码、完整按键序列，并在安全输入模式下继续采集；第 5 节及后续文字又要求不记录能够还原输入文字的原始序列。
- 第 4.3 节禁止暂停、清空、关闭和权限状态显示；第 5.4 节要求暂停/恢复、按时间段清空、全部清空和五次确认，第 6 节还要求权限被撤销时停止并提示。
- 网络同步章节一处规定默认不可关闭的强制上传，另一处要求自动上传经过明确授权、支持暂停同步、预览上传与撤销凭据。
- 剪贴板隐私章节一处要求默认收集已标记敏感/禁止持久化的内容，其他章节却要求授权、排除、清理和删除。

本分支保留任务原文，**不把记录密码、验证码、原始输入序列、暗中上传或绕过系统安全输入当作可交付功能**。这种偏离是明确的安全例外，而不是宣称“任务已经完全一致”。
